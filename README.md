# Cars Lab

A machine learning lab project using the `cars.csv` dataset. This project uses [`uv`](https://docs.astral.sh/uv/) to manage the Python environment and dependencies.

## Setup Steps (after cloning)

1. **Sync the environment** — `uv sync` (auto-creates `.venv` for Python 3.12 and installs deps).

2. **Activate the venv** — `.venv\Scripts\activate` (PowerShell) or `source .venv/bin/activate` (macOS/Linux).
   > Note: The VS Code Python extension may activate it for you automatically if you close and reopen a terminal.

3. **Create your lab branch** — name it `<first initial><last name>/cars`, e.g. `tsteele/cars`.
   > Cmd/Ctrl+Shift+p → "branch create" → name it and go.

4. **Set up your notebook** — no Jupyter or starter notebook is included on purpose. Use your AI assistant to do most of the work, create an `.ipynb`, and pick the `.venv` kernel. Figuring out the rest of the project structure is part of the exercise.
